CRUD de Produtos em Python

Sistema de gerenciamento de produtos desenvolvido em Python como projeto de estudo e evolução prática em programação.

Funcionalidades

* Cadastrar produtos
* Listar produtos
* Buscar produtos
* Editar produtos
* Remover produtos
* Validação de entradas
* Tratamento de exceções

Tecnologias

* Python
* Git
* GitHub

Objetivo

O projeto foi criado para praticar conceitos fundamentais de Python e acompanhar minha evolução no desenvolvimento de aplicações.

A aplicação será evoluída posteriormente com Programação Orientada a Objetos, banco de dados SQL e uma API REST.

Como executar

Clone o repositório, abra a pasta do projeto e execute o arquivo principal com Python.

python main.py
